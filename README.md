Generative AI disclosure:
Generative AI (Claude Sonnet 5) was used on this assignment as in accordance to the assignment parameters. It was primarily used to produce code helper functions (such as int to string conversions) which in those cases, is marked as so along with the prompts. I manually verified that those functions worked as intended with sample tests. As those helper functions were fairly trivial and could presumably be also found without modification on sites like stackoverflow, I did not encounter any bugs with them, but I did have to modify a couple of their inputs and outputs to avoid unnecessary casts. As this assignment was fairly trivial, I determined that it would be more efficient to handle the logic and parameters myself instead of using an AI to generate the code for the extractIpV4 function. Additionally, I used Claude Sonnet 5 for debugging. I had several issues regarding trailing text resulting in the entire ip being rejected; I pasted my ipv4 function into claude, asked it to look for issues, in which it displayed several lines that had issues, which saved time over manual code tracing and allowed me to quickly fix the lines.
